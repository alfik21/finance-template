Panduan Awal — 3 Langkah
Baru pertama kali membuka aplikasi? Ikuti urutan ini sampai data Anda tersambung.
  1. 1. Salin template ke Google Drive Anda dan jalankan menu Finance Tracker > Setup Awal di spreadsheet.
  2. 2. Otorisasi & deploy: Ekstensi > Apps Script > Deploy > New deployment (Execute as: User accessing the web app), lalu buka URL-nya di HP.
  3. 3. Pasang pintasan (Add to Home Screen) dan kelola dompet/kategori/anggaran lewat tab Pengaturan.
